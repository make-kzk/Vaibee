## 1. Что это такое

**Cornell Notes** (система конспектирования Корнелла) — структурированный метод записи и повторения учебного материала, разработанный в 1950-х годах **Уолтером Пауком** (Walter Pauk), профессором педагогики Корнеллского университета. Впервые описан в книге *How to Study in College* (1962).

Ключевая идея: конспект — не просто «запись лекции», а **инструмент для запоминания и понимания**. Разметка страницы — лишь форма; суть — в пятиступенчатом процессе работы с материалом до и после занятия.

| Подход | Фокус | Результат |
|--------|-------|-----------|
| Линейные записи | Зафиксировать всё подряд | Пассивный архив, сложно повторять |
| Mind Map | Визуальные связи | Хорош для обзора, слаб для деталей |
| **Cornell Notes** | **Запись + активное извлечение** | **Структурированный материал с встроенной самопроверкой** |

## 2. Структура страницы

Лист делится на **три зоны**:

```
┌─────────────────────────────────────────────────────┐
│  Тема / дата / курс                                 │
├──────────────┬──────────────────────────────────────┤
│              │                                      │
│   CUE        │         NOTES                        │
│  (подсказки) │      (основные записи)               │
│   ~30%       │         ~70%                         │
│              │                                      │
├──────────────┴──────────────────────────────────────┤
│  SUMMARY (краткое резюме — 2–3 предложения)         │
└─────────────────────────────────────────────────────┘
```

| Зона | Когда заполняется | Назначение |
|------|-------------------|------------|
| **Notes** (справа) | Во время лекции/чтения | Основные идеи, факты, формулы, схемы |
| **Cue** (слева) | В течение 24 часов после | Ключевые слова, вопросы, триггеры для вспоминания |
| **Summary** (внизу) | После обработки записей | Суть страницы своими словами |

## 3. Пять шагов (5 R's)

По [официальному описанию Cornell LSC](https://lsc.cornell.edu/notes.html), адаптированному из книги Паука:

### 3.1. Record (Запись)

Во время лекции записывайте материал в правую колонку **телеграфным стилем** — короткие фразы, аббревиатуры, списки. Цель — зафиксировать суть, а не дословную речь.

**Принципы записи:**
- фиксируйте общие идеи, а не каждую деталь;
- пропускайте строки между темами;
- используйте нумерацию для подпунктов;
- пишите разборчиво — конспект должен быть понятен через недели.

### 3.2. Reduce / Questions (Сокращение / Вопросы)

**Как можно скорее после занятия** (в идеале в течение 24 часов) перечитайте записи и заполните левую колонку:
- ключевыми словами;
- **вопросами** к каждому блоку заметок.

Это «обратный Jeopardy»: из утверждения формулируете вопрос, на который оно отвечает. Вопросы помогают:
- прояснить смысл;
- выявить связи между темами;
- подготовиться к экзаменам.

### 3.3. Recite (Повторение вслух)

Закройте правую колонку. Смотрите только на подсказки слева и **вслух** воспроизводите содержание своими словами. Затем откройте записи и проверьте себя.

Это **активное извлечение из памяти** (retrieval practice) — один из самых эффективных приёмов обучения по данным когнитивной науки.

### 3.4. Reflect (Размышление)

Задайте себе вопросы:
- В чём значение этих фактов?
- На каком принципе они основаны?
- Как применить это на практике?
- Как это связано с уже известным?
- Что лежит «за пределами» этой темы?

На этом этапе пишется **Summary** внизу страницы: 2–3 предложения, отвечающие на вопрос *«О чём эта страница?»*

### 3.5. Review (Повторный просмотр)

Регулярно (Паук рекомендовал **минимум 10 минут в неделю**) просматривайте все конспекты:
- читайте Summary для быстрого обзора;
- используйте Cue-колонку для самопроверки;
- применяйте **интервальное повторение** (spaced repetition).

## 4. Временная шкала работы

```
ЛЕКЦИЯ          →  0–24 ЧАСА        →  ПОВТОРЕНИЕ
────────          ──────────          ──────────
Record            Reduce + Reflect    Recite + Review
(Notes справа)    (Cue + Summary)     (самопроверка)
```

Большая часть ценности метода — **после занятия**, а не во время него.

---

## 5. Научная база

Метод опирается на принципы, подтверждённые когнитивной психологией:

| Принцип | Как реализован в Cornell |
|---------|--------------------------|
| **Retrieval practice** | Recite: воспроизведение из памяти по Cue-колонке |
| **Elaborative encoding** | Reflect: связь нового материала с уже известным |
| **Generation effect** | Reduce: формулирование вопросов усиливает запоминание |
| **Spaced repetition** | Review: регулярный просмотр с интервалами |
| **Summarization** | Summary: синтез и переформулирование своими словами |

## 6. Преимущества и ограничения

### Преимущества

1. **Структурированность** — материал разделён по функциям (запись / подсказки / резюме).
2. **Активное запоминание** — встроенная практика retrieval через Cue-колонку.
3. **Глубокая обработка** — Summary и Reflect заставляют синтезировать, а не просто копировать.
4. **Удобство для экзаменов** — вопросы в Cue-колонке уже готовы как тестовые карточки.
5. **Быстрый обзор** — можно «пролистать» весь курс, читая только Summary внизу каждой страницы.

### Ограничения

- **Требует времени** — на обработку после лекции нужно ~15–20 минут.
- **Нужна подготовка** — страницу нужно разметить заранее (или использовать шаблон).
- **Не для всего** — хуже подходит для математики с длинными выкладками, химических реакций, чертежей.
- **Риск формализма** — многие рисуют линии, но пропускают шаги Reduce, Recite и Reflect.

## 7. Сравнение с другими методами

| Метод | Фокус | Когда использовать |
|-------|-------|-------------------|
| **Cornell** | Запоминание + самопроверка | Лекции, семинары, чтение учебников |
| **Mind Map** | Визуальные связи | Мозговые штурмы, обзор тем |
| **Outline** | Иерархия и логика | Структурированные тексты |
| **Charting** | Сравнение категорий | История, биология, сравнительный анализ |

Cornell хорошо **комбинируется** с другими форматами — в правой колонке можно использовать и outline, и схемы.

## 8. Практические советы

**Хорошая подсказка (Cue):**
- «Причины ПМВ (4)» → напоминает перечислить четыре причины
- «Что такое фотосинтез?» → триггер для объяснения процесса

**Хорошее Summary:**
- 2–3 предложения своими словами;
- отражает **связь между идеями**, а не просто список фактов;
- должно быть понятно человеку, который видит только Summary.

**Цифровые инструменты:** Notability, GoodNotes, OneNote, Obsidian, Notion — все поддерживают шаблон Cornell.

## 10. Ключевой вывод

Cornell Notes — это не «шаблон с линиями», а **цикл обучения**:

> **Записать → Сформулировать вопросы → Воспроизвести из памяти → Осмыслить → Повторять с интервалами**

Метод особенно эффективен, когда важно не просто «иметь записи», а **долго помнить и понимать** материал.
