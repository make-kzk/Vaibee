**Status:** complete

## Правила подписи

**Формат:** `# {slug} — {название}`. Имя папки на диске — только slug.

## Что это

All-in-one workspace: заметки, базы данных, wiki, задачи. Гибкие блоки позволяют собирать любые рабочие пространства.

## Ключевые фичи

- Блочный редактор (текст, таблицы, embed, toggle)
- Базы данных с разными view (table, board, calendar, gallery)
- Вложенные страницы и иерархия
- Шаблоны и дублирование страниц
- Real-time collaboration

## UX-паттерны

- Slash-команды (`/`) для быстрого добавления блоков
- Hover-меню слева от блока для drag & reorder
- Breadcrumbs для навигации по иерархии
- Sidebar с деревом страниц

## Что понравилось

- Минимальный UI, контент в центре внимания
- Один продукт закрывает notes + wiki + light PM
- Базы данных без SQL — low barrier to entry

## Что можно позаимствовать

- Slash-меню для быстрых действий
- Карточный список заметок с preview
- Простая иерархия: workspace → page → subpage
