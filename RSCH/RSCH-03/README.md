# RSCH-03 — События

Материалы с конференций, воркшопов и отраслевых мероприятий: заметки, доклады, выводы.

## Правила подписи

**Формат:** `ID — Название`. Заголовок README — `# ID — Название`; имя папки на диске — только ID.

## Формат

Каждое событие — отдельная папка с README, agenda и insights. Заголовок README события: `# {slug} — {название мероприятия}`.
