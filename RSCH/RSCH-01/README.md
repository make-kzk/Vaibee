# RSCH-01 — Бизнес

Исследования продуктов, рынков и конкурентной среды.

## Правила подписи

**Формат:** `ID — Название`. Заголовок README — `# ID — Название`; имя папки на диске — только ID.

## Содержимое

| Подпись | Путь | Описание |
|---------|------|----------|
| products — Product research | [products/](./products/) | Разбор продуктов, UX-паттерны, выводы |

## Добавить исследование

```bash
cp -r SYST/templates/research RSCH/RSCH-01/products/my-product
# Заполните README.md, sources.md, insights.md
# Добавьте запись в SYST/catalog.json → "research"
```
