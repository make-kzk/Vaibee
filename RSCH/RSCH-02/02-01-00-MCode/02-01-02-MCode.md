# 02-01-02-MCode — Шаблон Team Motivational Map (MCode)

> Практический шаблон для заполнения после прохождения MCode assessment всеми участниками команды.  
> Раздел: [02-01-00-MCode — Motivation Code](./README.md) · Контекст: [02-01-01-MCode — Исследование MCode](./02-01-01-MCode.md)

---

## Как пользоваться

1. Каждый участник проходит [MCode assessment](https://motivationcode.com/assessment/) и сохраняет отчёт.
2. Лидер (или фасилитатор) собирает данные **с согласия** участников.
3. Заполняется **Раздел A** (профили) → **Раздел B** (карта) → **Раздел C** (анализ) → **Раздел D** (действия).
4. Карту пересматривают при изменении состава или каждые 6–12 месяцев.

Шаблон можно вести в Notion, Google Sheets, Miro или как markdown в этом репозитории.

### C4. Power Combinations (сильные пары/тройки)

| Участники | Комбинация измерений | Сильная сторона | Лучше всего для задач типа… |
|-----------|----------------------|-----------------|------------------------------|
| | Visionary + Orchestrator | Идея → структура → дедлайн | Новый продукт, roadmap |
| | Driver + Optimizer | Пробить + улучшить процесс | Технический долг, инциденты |
| | | | |

**Справочник для поиска power combos:**

| Если в команде есть… | Ищите пару с… | Результат |
|----------------------|---------------|-----------|
| Visionary (идеи) | Orchestrator (план) | Реализуемое видение |
| Driver (действие) | Optimizer (качество) | Быстро и правильно |
| Achiever (результат) | Relator (связь) | Результат + buy-in |
| Learner (знание) | Influencer (влияние) | Экспертиза + adoption |

---

### C5. Danger Zones (зоны трения)

| Пара участников | Clash измерений | Как проявляется | Как говорить (язык MCode) |
|-----------------|-----------------|-----------------|---------------------------|
| | Driver vs Visionary | «Давай быстрее» vs «ещё идеи» | «Нам нужен и Finish, и Explore — разделим фазы» |
| | Orchestrator vs Visionary | Процесс vs свобода | «Ты — vision, я — structure; границы фазы X» |
| | Optimizer vs Driver | «Сначала правильно» vs «go» | |
| | Achiever vs Relator | KPI vs люди | |

**Справочник типичных clash:**

| Clash | Суть конфликта | Депersonalized framing |
|-------|----------------|------------------------|
| Driver ↔ Optimizer | Скорость vs качество | «Clash Finish/Overcome и Do It Right» |
| Visionary ↔ Orchestrator | Хаос идей vs порядок | «Clash Explore и Systematize» |
| Achiever ↔ Relator | Результат vs отношения | «Clash Excel и Make the Team» |
| Influencer ↔ Learner | Влияние vs глубина | «Clash Persuade и Mastery» |

## Чеклист качества заполнения

- [ ] У каждого участника есть Top 5 Motivations и порядок 8 Dimensions
- [ ] Посчитаны концентрации и пробелы по измерениям
- [ ] Заполнены минимум 2 power combinations
- [ ] Зафиксированы минимум 2 danger zones с «депersonalized» формулировками
- [ ] Energy zones имеют явных owners
- [ ] Есть 90-day action plan с owner'ами
- [ ] Команда согласилась на shared language («мотивация, не характер»)
- [ ] Назначена дата review карты

---

## Принципы (из MCode)

1. **Не ярлык, а спектр** — «у Ивана слабый Driver» ≠ «Иван плохой исполнитель»; это «ему draining работать в режиме firefight».
2. **Конфликт ≠ личность** — «clash мотиваций, не clash людей».
3. **Согласие на данные** — профили sharing только добровольно.
4. **Карта живая** — обновлять при смене состава, роли или после крупных проектов.
