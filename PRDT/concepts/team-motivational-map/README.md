## Идея

Интерактивный click-through пример заполненной Team Motivational Map — визуализация результата шаблона [02-01-02-MCode — Шаблон Team Motivational Map](../../../RSCH/RSCH-02/02-01-00-MCode/02-01-02-MCode.md).

## Гипотеза

Команде нужен не PDF-отчёт, а наглядная карта: концентрации, пробелы, power combos и danger zones — в одном месте, с drill-down по участникам.

## Ключевые экраны

1. **Overview** — one-page view (Раздел E)
2. **Dimensions** — heatmap 8 измерений (C1)
3. **Profiles** — список участников → профиль (B1)
4. **Energy Zones** — кто energize/drain по фазам (C3)
5. **Power Combos** — сильные пары (C4)
6. **Danger Zones** — зоны трения (C5)
7. **Actions** — план на 90 дней (D3)
