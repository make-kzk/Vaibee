# 12DF Artifacts — интерактивный мокап

**Status:** draft  
**Date:** 2026-09-05  
**Tags:** 12df, motivation, team, tti, artifacts

## Идея

Click-through прототип всех практических артефактов методологии **12 Driving Forces** (A–H): от персонального отчёта до матрицы напряжений команды и протокола 1:1 — на демо-данных команды «Продукт Альфа».

## Гипотеза

HR, руководители и фасилитаторы не читают 40-страничный markdown — им нужен **наглядный поток**: «отчёт → разбор → план → команда → найм», с drill-down по каждому артефакту и связями между экранами.

## Ключевые экраны

| Экран | Артефакт | `data-screen` |
|-------|----------|---------------|
| Home — цепочка + кейс удержания | §1, §11 | `home` |
| Персональный отчёт | A (A1–A4) | `report-a` |
| Ранжирование 12 сил | A2 | `report-a2` |
| Портрет и кластеры | A3 | `report-a3` |
| Стресс и коммуникация | A4 | `report-a4` |
| Карточка кластера | B | `cluster-b` |
| Лист разбора | C | `debrief-c` |
| План действий | D | `plan-d` |
| Карта команды | E | `team-e` |
| Профиль участника | E2 drill-down | `member-{id}` |
| Матрица напряжений | F + F2 | `tension-f` |
| Эталон должности | G | `benchmark-g` |
| Протокол 1:1 | H | `oneone-h` |
