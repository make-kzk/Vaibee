**Status:** draft

## Правила подписи

**Формат:** `# {slug} — {название}`. Имя папки на диске — только slug.

## Идея

Минималистичное приложение для заметок: список → деталь → создание. Без баз данных и сложных блоков.

## Гипотеза

Большинству пользователей нужен быстрый capture + организация, а не полная гибкость Notion.

## Ключевые экраны

1. **Home** — список заметок с preview
2. **Detail** — просмотр заметки
3. **New** — создание новой заметки
