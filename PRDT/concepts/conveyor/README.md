## Идея

**Бесшовный** click-through прототип конвейера найма в стиле **VibeHunt88**: шаги 1–2 в одном flow без перезагрузки страницы.

SSOT: [PRDT-01-01-01-conveyor](../../PRDT-01-00-00/PRDT-01-01-ideas/PRDT-01-01-01-conveyor.md)

## Flow

1. **Landing + JTBD** → регистрация HR
2. **Онбординг** → компания → HeadHunter
3. **Публикация вакансии** → wizard (роль → профиль → этапы → календарь → HH)
4. **Teaser шага 3** — назначение встречи

Навигация «Вакансии» открывается только после завершения онбординга (компания + HH).
